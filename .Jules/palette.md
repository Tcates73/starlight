## 2026-05-21 - Custom visual meters need ARIA roles and keyboard focus should be visible
**Learning:** Using semantic HTML element (`div` with custom styles) for visual meters requires specific ARIA roles to be exposed to screen readers. Specifically, `role="meter"` along with `aria-valuemin`, `aria-valuemax`, and a dynamically updated `aria-valuenow` provides the necessary context. Using `aria-labelledby` and `aria-describedby` further associates the meter with its visible text labels. Additionally, relying on default browser styles for inputs often results in poor keyboard focus indication.
**Action:** When creating custom visual meters or progress bars using non-semantic elements, always add `role="meter"` (or `role="progressbar"`) and dynamically update their `aria-valuenow` attribute. Ensure custom form inputs have explicit `:focus-visible` styles with a clear outline and offset.

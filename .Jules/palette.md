## 2025-02-23 - Dynamic Meter ARIA & Live Regions
**Learning:** Found that custom visual "meters" (like the Family Budget Game's health and stress meters) built using standard `<div>` wrappers are completely opaque to screen readers by default. When the width dynamically updates, visual users see it, but screen readers hear nothing. Also, real-time summaries require `aria-live="polite"` so screen readers dynamically announce updates.
**Action:** When implementing custom visual progress bars or meters in the future, always apply `role="progressbar"`, set `aria-valuemin` and `aria-valuemax`, and programmatically keep `aria-valuenow` synced via JavaScript. Always attach `aria-live="polite"` to textual summary containers that give users contextual updates while filling out forms.
